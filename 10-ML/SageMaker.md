## What Problem Does It Solve?

Helps developers and data scientists build machine learning models without having to manage the entire machine learning infrastructure themselves.

**SageMaker** solves the complexity of bringing the machine learning process together in one managed service.

Think:

Data

↓

SageMaker

↓

Build ML Model

↓

Train ML Model

↓

Deploy ML Model

### Memory Trick

SageMaker = Build ML Models

## What Is Amazon SageMaker?

Amazon SageMaker is a:

Fully Managed Machine Learning Service

It is designed for:

- Developers
- Data scientists

to build machine learning models.

Your course emphasizes that machine learning can normally require:

Multiple Processes

+

Server Provisioning

SageMaker helps bring those processes together into a managed environment.

### Memory Trick

SageMaker = Managed ML Platform

## Machine Learning Process

For CCP, think of SageMaker as supporting the machine learning lifecycle:

Build

↓

Train

↓

Deploy

### Build

Create and develop the machine learning model.

### Train

Train the model using data.

### Deploy

Make the trained model available for use.

### Memory Trick

SageMaker = BUILD → TRAIN → DEPLOY

---

## Fully Managed

SageMaker is:

Fully Managed

AWS handles much of the underlying infrastructure required for machine learning workloads.

This helps developers and data scientists focus more on:

Machine Learning

rather than:

Provisioning Infrastructure

## SageMaker vs Rekognition

### [[SageMaker]]

Think:

BUILD ML MODELS

### [[Rekognition]]

Think:

ANALYZE IMAGES / VIDEO

Rekognition provides an AWS AI service for visual analysis.

SageMaker provides the broader platform for building machine learning models.

### Memory Trick

SageMaker = BUILD ML

Rekognition = SEE
