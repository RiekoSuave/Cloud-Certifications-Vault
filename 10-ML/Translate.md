## What Problem Does It Solve?

Translates languages automatically.

**Translate** solves the problem of communicating across different languages by automatically translating content from one language into another.

Language A

↓

Translate

↓

Language B

## Translate vs Comprehend

These both work with language, but they solve different problems.

### [[Translate]]

Changes:

One Language

↓

Another Language

### [[Comprehend]]

Analyzes and understands:

TEXT

using Natural Language Processing.

### Memory Trick

Translate = CHANGE LANGUAGE

Comprehend = UNDERSTAND TEXT
