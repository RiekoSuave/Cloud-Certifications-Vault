## Overview

The AWS Cloud Adoption Framework — AWS CAF — helps organizations:

**Build and execute a comprehensive plan for digital transformation using AWS**

It was created using:

- AWS best practices
- Lessons learned from thousands of customers
- Experience from AWS professionals

AWS CAF identifies:

**Organizational capabilities that support successful cloud transformation**

These capabilities are grouped into:

**Six Perspectives**

1. Business
2. People
3. Governance
4. Platform
5. Security
6. Operations

> [!tip] Memory Trick
> **B-P-G-P-S-O**
>
> **B**usiness  
> **P**eople  
> **G**overnance  
> **P**latform  
> **S**ecurity  
> **O**perations

---

## What AWS CAF Is For

AWS CAF is not primarily about:

**Designing one application**

Instead, it focuses on:

**Helping an organization transform through cloud adoption**

Think about:

- Business goals
- Organizational change
- Governance
- Technology platforms
- Security
- Operations

### Killer Exam Clue

> **Organization needs a structured framework to guide cloud transformation**
>
> → **AWS CAF**

---

# 1. Business Perspective

The Business Perspective helps ensure that:

**Cloud investments support digital transformation and business outcomes**

It focuses on:

**Connecting cloud adoption to business value**

### Think About

- Business goals
- Business outcomes

- Value from cloud investments

### Killer Exam Clue

> **Ensure cloud investment supports business objectives**
>
> → **Business Perspective**

# 2. People Perspective

The People Perspective acts as a bridge between:

**Technology**

and:

**Business**

It helps organizations evolve toward:

**A culture of continuous growth and learning**

The course highlights areas such as:

- Culture
- Organizational structure
- Leadership
- Workforce

### Core Idea

Cloud transformation is not just:

**Technology change**

It also requires:

**People and organizational change**

### Killer Exam Clue

>
> → **People Perspective**

### Memory Trick

> **PEOPLE = WHO MUST CHANGE WITH THE CLOUD?**

# 5. Security Perspective

The Security Perspective helps achieve:

- Confidentiality
- Integrity
- Availability

for:

**Data and cloud workloads**

### CIA Triad

**Confidentiality**

→ Only authorized access

**Integrity**

→ Data remains accurate and protected from improper change

**Availability**

→ Systems and data remain accessible when needed

### Killer Exam Clue

> **Protect confidentiality, integrity, and availability**
>
> → **Security Perspective**

### Memory Trick

> **SECURITY = PROTECT THE CLOUD TRANSFORMATION**

See:

[[Shared Responsibility Model]]

# Align

The Align phase identifies:

**Capability gaps**

**Six AWS CAF Perspectives**

**An Action Plan**

### Memory Trick

> **ALIGN = WHAT ARE WE MISSING?**

> → **Launch**

### Memory Trick

# AWS CAF vs Well-Architected Framework

These are NOT the same thing.

## AWS CAF

Focuses on:

**Organizational cloud transformation**

Think:

- Business
- People
- Governance
- Platform
- Security
- Operations

## [[Well-Architected Framework]]

Focuses on:

**Architecture best practices for workloads**

Think:

- Operational Excellence
- Security
- Reliability
- Performance Efficiency
- Cost Optimization
- Sustainability

### Killer Shortcut

> **ORGANIZATION TRANSFORMATION**
> → AWS CAF
>
> **WORKLOAD ARCHITECTURE**
> → WELL-ARCHITECTED FRAMEWORK
