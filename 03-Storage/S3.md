## What Problem Does It Solve?

Provides highly scalable object storage for files and data.

S3 can store massive amounts of data and provides different storage classes and lifecycle options to help optimize storage costs.

---

## Type

Object Storage

---

## What Is S3?

S3 stands for:

Simple Storage Service

S3 is one of the main building blocks of AWS.

It is designed to provide extremely scalable storage for objects.

### Memory Trick

S3 = Store Stuff Simply

---

## Object Storage

S3 stores data as:

Objects

Objects are stored inside:

Buckets

Basic Structure:

Bucket

↓

Object

### Memory Trick

S3 = Buckets + Objects

---

## S3 Buckets

Buckets contain objects.

Buckets are created within an AWS Region.

Although S3 can appear to be a global service, the individual buckets are associated with a Region.

---

## Bucket Names

Bucket naming depends on the namespace being used.

Your course notes distinguish between:

- Shared Global Namespace
- Account Regional Namespace

For the shared global namespace, bucket names must be globally unique across AWS accounts and Regions.

---

## Bucket Naming Rules

Your course notes identify rules including:

- No uppercase letters
- No underscores
- Cannot be formatted as an IP address
- Must begin with a lowercase letter or number
- Cannot begin with `xn--`
- Cannot end with `-s3alias`

---

## S3 Objects

Files stored in S3 are called:

Objects

Each object has a:

Key

The key identifies the object inside the bucket.

---

## Object Keys

The key represents the full path to the object.

Example:

`s3://my-bucket/my_file.txt`

Another example:

`s3://my-bucket/my_folder1/another_folder/my_file.txt`

The key consists of:

Prefix + Object Name

---

## S3 Does Not Really Have Folders

S3 is object storage.

There is no traditional directory structure inside a bucket.

What looks like folders in the interface is created using object keys containing `/`.

### Memory Trick

S3 folders = Key prefixes

## S3 vs EBS

### S3

Object storage.

### EBS

Block storage primarily used with EC2.

| S3 | EBS |
|---|---|
| Object storage | Block storage |
| Buckets + objects | Volumes |
| Massive scalability | EC2 disk |
| File/object-oriented | Block-oriented |

---

## S3 vs EFS

### S3

Object storage accessed using S3 mechanisms/APIs.

### EFS

Shared filesystem for Linux workloads.

| S3 | EFS |
|---|---|
| Object storage | File storage |
| Buckets | Filesystem |
| Objects | Files/directories |
| Massive object storage | Shared EC2 filesystem |
