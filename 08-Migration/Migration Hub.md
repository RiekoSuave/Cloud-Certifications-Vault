## Migration Hub vs DMS

### Migration Hub

Tracks and manages:

Migrations

### DMS

Migrates:

Databases

| Migration Hub | DMS |
| --- | --- |
| Migration management | Database migration |
| Central visibility | Moves database data |
| Tracks progress | Minimal downtime |
| Assessment & planning | Database-focused |
