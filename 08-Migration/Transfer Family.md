## What Problem Does It Solve?

Provides managed file transfers using familiar file transfer protocols.

AWS Transfer Family solves the problem of managing file transfer infrastructure when organizations need to transfer files into and out of AWS.

### Memory Trick

Transfer Family = Managed File Transfer

## Type

Managed File Transfer

## Transfer Family vs Snow Family

This is the most important comparison for this section.

### Transfer Family

Think:

NETWORK FILE TRANSFER

### Snow Family

Think:

PHYSICAL DATA TRANSFER

| Transfer Family | Snow Family |
| --- | --- |
| File transfers | Huge data transfers |
| Network-based | Physical devices |
| FTP / SFTP | Offline migration |
| Managed file transfer | Massive dataset migration |

→ DMS

NOT Transfer Family
