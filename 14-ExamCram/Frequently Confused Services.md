CloudWatch vs CloudTrail

CloudTrail = Who did what/audit logs

CloudWatch = Monitor resources/metrics/logs/alarms

---

S3 vs EBS vs EFS

S3 = Objects

EBS = EC2 disk

EFS = Shared storage

---

Shield vs WAF

Shield = DDoS

WAF = Web filtering

---  
  
Security Groups vs NACLs  
  
Security Groups = instance level / stateful  
  
NACLs = subnet level / stateless  
  
---  
  
ECS vs EKS  
  
ECS = AWS containers  
  
EKS = Kubernetes  
  
---  
  
Glacier vs Deep Archive  
  
Glacier = archive  
  
Deep Archive = cheapest archive
