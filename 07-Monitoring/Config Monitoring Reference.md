## Monitoring Focus

AWS Config tracks AWS resource configurations and compliance.

Use this Monitoring reference to remember:

Config = What Changed?

---

## What Does Config Track?

Config focuses on:

- Resource configurations
- Configuration history
- Compliance
- Changes to resources

### Memory Trick

Config = Resource Configuration History

---

## Monitoring Use Cases

- Configuration compliance
- Resource tracking
- Change management

---

## Config vs CloudTrail

Config = Resource Configuration

CloudTrail = API Activity

### Memory Trick

Config = WHAT CHANGED?

CloudTrail = WHO DID IT?

---

## Config vs CloudWatch

Config = Configuration Tracking

CloudWatch = Metrics, Logs & Alarms

### Memory Trick

Config = CONFIGURATION

CloudWatch = PERFORMANCE

---

## Exam Recognition

"How has this resource's configuration changed?"

→ Config

"Track resource configuration history"

→ Config

"Check resource configuration compliance"

→ Config

"Who made an API call?"

→ CloudTrail

NOT Config

"Monitor CPU utilization"

→ CloudWatch

NOT Config
