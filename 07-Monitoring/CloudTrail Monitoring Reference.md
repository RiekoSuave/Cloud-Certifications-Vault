## Monitoring Focus

CloudTrail records AWS API activity and account actions.

Use this Monitoring reference to remember:

CloudTrail = Who Did What?

---

## What Does CloudTrail Track?

CloudTrail helps answer questions such as:

Who performed an action?

What action was performed?

When did the action occur?

### Memory Trick

CloudTrail = AWS Activity History

---

## Monitoring Use Cases

- Auditing AWS activity
- Reviewing account actions
- Investigating API activity
- Troubleshooting events
- Security investigations

---

## CloudTrail vs CloudWatch

CloudTrail = API Activity

CloudWatch = Metrics, Logs & Alarms

### Memory Trick

CloudTrail = WHO DID IT?

CloudWatch = WHAT IS HAPPENING?

---

## CloudTrail vs Config

CloudTrail = Tracks Actions

Config = Tracks Resource Configuration

### Memory Trick

CloudTrail = WHO DID WHAT?

Config = WHAT CHANGED?

---

## Exam Recognition

"Who made this API call?"

→ CloudTrail

"Who deleted this AWS resource?"

→ CloudTrail

"What actions occurred in this AWS account?"

→ CloudTrail

"Monitor CPU utilization"

→ CloudWatch

NOT CloudTrail

"Track resource configuration changes"

→ Config

NOT CloudTrail

---
