## What Problem Does It Solve?

Provides third-party software and solutions.

**AWS Marketplace** solves the "buy vs. build" problem by providing a digital catalog of third-party software and prebuilt solutions that run on AWS.

Think:

Need Software

↓

AWS Marketplace

↓

Third-Party Solution

### Memory Trick

Marketplace = AWS App Store

## What Is AWS Marketplace?

AWS Marketplace is a:

DIGITAL CATALOG

for:

THIRD-PARTY SOFTWARE

and

PREBUILT SOLUTIONS

that run on AWS.

### Memory Trick

Marketplace = Shop for AWS Software

## Third-Party Software

The most important concept is:

THIRD-PARTY SOFTWARE

This means the software comes from vendors rather than being an AWS-native service.

Think:

Need Third-Party Software

↓

[[Marketplace]]

### Memory Trick

Third-Party Software = Marketplace

---

## Prebuilt Solutions

Marketplace provides access to:

PREBUILT SOLUTIONS

Instead of building everything yourself, you can find existing software solutions that can be used with AWS.

Think:

BUILD IT YOURSELF

vs

BUY EXISTING SOLUTION

↓

[[Marketplace]]

### Memory Trick

Marketplace = Buy Instead of Build

---

## Subscription Options

Your course also associates Marketplace with:

SUBSCRIPTION OPTIONS

This allows customers to obtain third-party software through the Marketplace.

### Memory Trick
