## What Is AWS CDK?

AWS CDK is used to:

DEFINE CLOUD INFRASTRUCTURE

using a:

PROGRAMMING LANGUAGE

For your course, this is the main association to remember.

### Memory Trick

CDK = Code Your Infrastructure

---

## Infrastructure as Code

CDK belongs to the broader concept of:

Infrastructure as Code

or:

IaC

Instead of manually creating cloud infrastructure, you define the infrastructure using code.

### Memory Trick

IaC = Infrastructure Defined With Code
