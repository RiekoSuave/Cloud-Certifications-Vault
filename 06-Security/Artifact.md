## What Problem Does It Solve?

Provides on-demand access to AWS security and compliance documents and AWS agreements.

AWS Artifact helps organizations obtain compliance documentation needed for:

- Audits
- Compliance reviews
- Internal reviews
- AWS agreements

Artifact = AWS Compliance Documents

## Type

Compliance Portal

## What Is AWS Artifact?

AWS Artifact is a portal that provides customers with on-demand access to:

- AWS compliance documentation
- AWS agreements

Your course notes that Artifact is not really a traditional AWS service.

Think of it as a:

Self-Service Compliance Portal

### Memory Trick

Artifact = Compliance Paperwork

---

## Two Important Parts

The two major concepts to remember are:

1. Artifact Reports
2. Artifact Agreements

---

## Artifact Reports

Artifact Reports provides access to AWS security and compliance documents from third-party auditors.

Examples from your course include:

- ISO certifications
- PCI reports
- SOC reports

### Use Artifact Reports When:

A company needs AWS compliance or audit documentation.

### Memory Trick

Artifact Reports = Read / Download Reports

---

## Artifact Agreements

Artifact Agreements allows customers to:

- Review agreements
- Accept agreements
- Track agreement status

Your course gives the:

Business Associate Addendum (BAA)

as an example.

Agreements can apply to:

- An individual AWS account
- An AWS Organization

### Memory Trick

Artifact Agreements = Review / Accept Agreements

---

## Reports vs Agreements

| Artifact Reports | Artifact Agreements |
|---|---|
| Compliance documents | AWS agreements |
| Audit reports | Review agreements |
| ISO | Accept agreements |
| PCI | Track agreement status |
| SOC | Example: BAA |

### Memory Trick

Reports = Documents

Agreements = Contracts

Artifact Reports = Audit / Compliance Reports

Artifact Agreements = AWS Agreements
