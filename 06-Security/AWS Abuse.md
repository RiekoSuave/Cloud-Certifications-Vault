## What Problem Does It Solve?

Provides a way to report AWS resources being used for abusive or illegal purposes.

### Memory Trick

AWS Abuse = Report Abuse

---

## Type

Abuse Reporting

---

## What Is AWS Abuse?

AWS Abuse is used to report:

AWS Resources

that are being used for:

- Abusive purposes
- Illegal purposes

Think:

AWS Resource

↓

Used for Abuse / Illegal Activity

↓

Report to AWS Abuse

### Memory Trick

AWS Resource Being Abused?

→ AWS Abuse

---

## Common Use Cases

- Reporting abusive use of AWS resources
- Reporting AWS resources used for illegal purposes

AWS resources are being used for abusive purposes and need to be reported.

## Don't Confuse These

AWS Abuse = Report Abusive / Illegal Use

GuardDuty = Detect Malicious Behavior

Detective = Investigate Root Cause

Security Hub = Gather Security Findings

### Memory Trick
